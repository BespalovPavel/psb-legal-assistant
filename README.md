# PSB Legal Assistant — Веб-контур и RAG-система

Юридический ИИ-ассистент с контролем достоверности нормативных документов, гибридным поиском (BM25 + Char-WB TF-IDF + Dense Embeddings + Reranker) и персистентным хранением контекста диалогов.

## База данных

В веб-контуре используется **исключительно СУБД PostgreSQL 14+**.
Файловые базы данных не используются и не поддерживаются архитектурой: сервис строго опирается на PostgreSQL (типы `UUID`, `JSONB`, внешние ключи с каскадным удалением и генерацию UUID на стороне сервера).

### Зависимости проекта

- Корневой `requirements.txt` содержит ровно 9 строк, заморожен и используется исключительно для сборки ZIP-сабмита платформы.
- Все зависимости веб-контура зафиксированы в `requirements-web.txt` (включая `psycopg2-binary==2.9.10` и `alembic==1.16.2`).

## Запуск приложения

### Путь A. Запуск через Docker (для жюри)

Запуск всего контура (PostgreSQL + FastAPI веб-сервис) выполняется одной командой:

```bash
docker compose up --build
```

Сервис базы данных запустится на порту `5432`, применит healthcheck `pg_isready`, после чего запустится backend-сервис на порту `8000`, применит миграции Alembic и запустит uvicorn.

---

### Путь B. Локальный запуск без Docker (для разработки)

#### 1. Установка и настройка PostgreSQL

Убедитесь, что установлен и запущен локальный сервер PostgreSQL 14+.
Создайте базу данных и пользователя:

```sql
CREATE DATABASE legal_assistant;
CREATE USER assistant WITH PASSWORD 'assistant';
GRANT ALL PRIVILEGES ON DATABASE legal_assistant TO assistant;
```

Если вы переключаетесь со старой dev-схемы, выполните сброс таблиц перед запуском:

```bash
psql -U assistant -d legal_assistant -f scripts/reset_db.sql
```

#### 2. Установка зависимостей веб-контура

```bash
pip install -r requirements-web.txt
```

> **Примечание для корпоративных сетей:** при наличии корпоративного прокси используйте флаги доверенных хостов или сертификат компании:
> ```bash
> pip install -r requirements-web.txt --trusted-host pypi.org --trusted-host files.pythonhosted.org
> ```

#### 3. Настройка переменных окружения

Скопируйте шаблон `.env.example` в `.env` и укажите параметры подключения к БД и LLM API:

```bash
cp .env.example .env
```

#### 4. Применение миграций

```bash
alembic upgrade head
```

#### 5. Запуск веб-сервера

```bash
python main.py
```

Или через uvicorn напрямую:

```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```

При первом запуске при пустой таблице `documents` lifespan-обработчик автоматически выполнит первичный инджест базы знаний из каталога `data/knowledge-base`.

## Переменные окружения (.env)

| Переменная | Описание | Значение по умолчанию |
|---|---|---|
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgresql+psycopg2://assistant:assistant@localhost:5432/legal_assistant` |
| `POSTGRES_DB` | Имя базы данных PostgreSQL | `legal_assistant` |
| `POSTGRES_USER` | Пользователь PostgreSQL | `assistant` |
| `POSTGRES_PASSWORD` | Пароль пользователя PostgreSQL | `assistant` |
| `LLM_BASE_URL` | Базовый URL OpenAI-совместимого API | `https://api.your-provider.example/v1` |
| `LLM_API_KEY` | Ключ доступа к API языковой модели | — |
| `LLM_MODEL` | Имя генеративной модели | `deepseek/deepseek-v4.1-flash` |
| `EMB_MODEL` | Модель векторных представлений | `baai/bge-m3` |
| `RERANKER_MODEL` | Модель кросс-энкодера реранкинга | `Qwen/Qwen3-Reranker-8B` |

Сетевые порты:
- `8000`: FastAPI HTTP веб-сервис
- `5432`: PostgreSQL

## Проверка основного пользовательского сценария

1. **Создать чат:** отправьте `POST /api/chats` с телом `{"title": "Тестовый чат"}` и получите `chat_id`.
2. **Задать вопрос:** отправьте `POST /api/chats/{chat_id}/messages` с текстом вопроса по нормативным актам или договорам.
3. **Получить ответ с источниками:** убедитесь, что ответ содержит поле `answer` и список релевантных `sources` с цитатами и путями.
4. **Открыть источник:** по полученному `chunk_id` запросите `GET /api/chunks/{chunk_id}` и проверьте фрагмент документа.
5. **Проверить историю диалога:** обновите страницу, вызовите `GET /api/chats/{chat_id}` и убедитесь, что все сообщения и источники сохранены.
6. **Уточняющий вопрос:** отправьте следующий вопрос (например, "А какой гарантийный срок?") и убедитесь, что ответ сформирован с учётом контекста предшествующего диалога.

## Известные ограничения

- **Редакции законодательства:** законодательные акты в базе знаний представлены исключительно в актуальной действующей редакции.
- **Отказ при нехватке данных / сбое LLM:** при недоступности внешнего сервиса LLM или отсутствии нормативных документов веб-контур возвращает регламентный обоснованный отказ без галлюцинаций.
- **Модель сабмита:** на соревновательной платформе используется модель DeepSeek V4.1 Flash через прокси организаторов; для локальной разработки требуется собственный OpenAI-совместимый эндпоинт, указанный в `.env`.
